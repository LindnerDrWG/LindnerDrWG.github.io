% use special function iGamma, with is autoloaded
% the regularized lower incomplete gamma function

procedure chi2CDF(x, k);
          if x<=0 or k<=0 then 0.0 
          else iGamma(k*0.5, x*0.5) $

% ------------------- Example usage ---------------------


on rounded $
print_precision 5$

chi2CDF(1,3);   %% = R: 0.198748



% ------------------- alternative definition I ------------
% using a user-defined function GammaP(a,b), i.e. P(a,b)

COMMENT
  If you prefer to define chi2CDF from first principles, 
  the cumulative distribution function chi2CDF(x,k) 
  for a Chi-Squared distribution is given by 
  the regularized lower incomplete gamma function
  using a self-defined GammaP(a,b) alias P(a,b) $

procedure GammaP(x,k); 
          x^k*exp(-x) * for m:=0:100 sum x^m/gamma(k+m+1)$

procedure chi2CDF2(x, k);
          if x<=0 or k<=0 then 0.0 
          else GammaP( x*0.5, k*0.5) $ 

on rounded $
print_precision 5$

chi2CDF2(1,3);   %% = R: 0.198748
